## 📜 O Projekcie

**[Nazwa Twojej Gry]** to trójwymiarowa gra przygodowa osadzona w głębokim, mrocznym świecie mitologii słowiańskiej. Projekt tworzony na silniku Unity 3D, kładący nacisk na gęstą atmosferę, eksplorację zapomnianych ruin i interakcję z istotami znanymi z ludowych podań.

Celem gry jest [krótki opis celu, np.: odnalezienie drogi do domu, zdjęcie klątwy, odbudowa kaplicy Światowida].

## 🎮 Główne Mechaniki

* **Eksploracja:** Otwarty świat inspirowany krajobrazami Europy Środkowo-Wschodniej (gęste bory, mokradła, drewniane osady).
* **Bestiariusz:** Spotkania z Leszymi, Rusałkami, Południcami i innymi istotami z podań.
* **System Rytuałów:** Mechanika oparta na zbieraniu ziół i składaniu ofiar w celu zjednania sobie przychylności bóstw.
* **Dynamiczna Pogoda:** Zmienne warunki atmosferyczne wpływające na rozgrywkę i zachowanie otoczenia.

## 🎵 Ścieżka Dźwiękowa

Atmosferę gry buduje wyjątkowa oprawa muzyczna. W grze wykorzystano utwory autorstwa **Mia Hipnosis**, za oficjalnym pozwoleniem artystki.

Muzyka łączy w sobie brzmienia etniczne, transowe i ambientowe, idealnie oddając ducha słowiańskiej tajemnicy.

## 🚀 Jak uruchomić projekt

1.  Sklonuj repozytorium:
    ```bash
    git clone [https://github.com/twoj-nick/nazwa-repozytorium.git](https://github.com/twoj-nick/nazwa-repozytorium.git)
    ```
2.  Otwórz **Unity Hub**.
3.  Kliknij `Add` i wskaż folder z pobranym projektem.
4.  Otwórz scenę `MainMenu` znajdującą się w folderze `Assets/Scenes`.
