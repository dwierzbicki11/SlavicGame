# SlavicGame audio pack

Original procedural audio created for SlavicGame. No third-party samples are used.

Music:
- r0_day_woodland.wav — calm woodland/day exploration loop
- r0_night_marsh.wav — nocturnal marsh/supernatural loop
- combat_predator.wav — combat loop
- ritual_threshold.wav — ritual/threshold loop

SFX:
- melee_swing, bow_draw, bow_release, magic_cast, ritual_start
- interaction_pickup, water_splash, impact_hit, jump
- ui_confirm, ui_back

Runtime format: PCM16 mono, 24 kHz WAV, matching the existing SDL2 audio backend.
