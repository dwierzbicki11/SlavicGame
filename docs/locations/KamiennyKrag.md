# Lokacja: Kamienny Krąg — karta v0.1

**ID:** `old-shrine`  
**Typ:** shrine / ritual site  
**Status:** F

## Funkcja

Miejsce:
- nauki pierwszego rytuału;
- nauki znaków;
- kontaktu ze shrine-keeper;
- opcjonalnej relacji boskiej.

## Zasada źródłowa

Układ miejsca i rytuał są autorskie F.

Nie przedstawiamy „kamiennego kręgu” jako standardowej historycznej słowiańskiej świątyni bez osobnego researchu.

- podejście boczną ścieżką;
- zewnętrzne kamienie;
- centralne pole rytuału;
- miejsce instruktażu;
- opcjonalny punkt manifestacji/posłańca.

## Dzień

## Noc

Nie może być wymagany do ukończenia „Światła nad mokradłem”.

Gracz może:
- wysłuchać;
- odmówić;
- negocjować;
- odejść.
