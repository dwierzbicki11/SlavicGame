# Geografia makroświata — v0.1

Mapa nie odpowiada realnej Europie.

## Oś geograficzna

### Wielka Rzeka Dębrza F

Główna arteria Nadborza.

Płynie:
- z południowych wyżyn;
- przez ziemie grodowe;
- do Przymorza.

Tworzy:
- porty;
- brody;
- cła;
- tereny zalewowe;
- powody konfliktów.

## Regiony gry

### R0 — Pogranicze Żarnowca

Mały region startowy między:
- drogą do Nadborza;
- skrajem Wielkiego Boru;
- mokradłami odpływów Dębrzy.

### R1 — Nadborze

Gęściej zaludniony region rzeki.

Miejsca:
- Dębrzyn;
- kilka grodów zależnych;
- młyny;
- pola;
- święte miejsca;
- stara sieć dróg.

### R2 — Wielki Bór

Ogromna puszcza.

Nie cały obszar jest grywalny naraz.

Region gry obejmuje:
- osady brzegowe;
- trzy głębsze strefy;
- stare miejsca;
- szlaki sezonowe.

### R3 — Przymorze

Ujście Dębrzy i wybrzeże.

Miejsca:
- Solny Bród;
- mniejsze porty;
- wyspy;
- słone mokradła;
- klify.

### R4 — Kamienne Wyżyny

Południowe pasma.

Miejsca:
- Wysokamień;
- Żelazna Brama;
- kopalnie;
- przełęcze;
- górskie miejsca kultowe.

### R5 — Równiny Arel

Wschodnie/południowo-wschodnie otwarte tereny.

Miejsca:
- stałe osady;
- sezonowe obozy;
- szerokie trasy;
- stare kurhany/stanowiska wymagające osobnego researchu kulturowego.

### R6 — Pustkowie Pierwszego Progu

Późnogrowa strefa.

Nie jest martwą pustynią.

Charakter:
- rzadkie osadnictwo;
- ruiny;
- niestabilne miejsca;
- ślady starszych systemów;
- konflikty ekspedycji.

## Sfery poza mapą Jawii

### Nawia

Dostęp:
- przez konkretne progi;
- później przez kontrolowane wejścia.

Ma własną geometrię i logikę, nie jest kopią mapy Jawii.

### Sfera boska

Nie jest jednym wspólnym hubem.

Dostęp:
- przejawy;
- miejsca;
- domeny;
- wysłannicy.

### Czwarta Sfera

Jej mapa jest definiowana dopiero w finalnym lore.

## Odległości produkcyjne

Każdy region jest osobnym dużym obszarem.

Nie tworzymy seamless kontynentu tylko po to, by podróż trwała godzinami.

Przejścia między regionami mogą używać:
- podróży;
- loading;
- krótkiej sekwencji;
- mapy świata.

## Powroty

Main story wraca do wcześniejszych regionów po zmianie:
- polityki;
- pory;
- kryzysu;
- granic sfer.

Region nie jest jednorazowym poziomem.
