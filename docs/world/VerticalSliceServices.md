# Usługi Pogranicza Żarnowca — v0.1

## Zielarka

Usługi:
- zakup prostych składników;
- crafting/uczenie receptury;
- leczenie lub consumables;
- informacje biologiczne.

Quest gating:
- część receptur po zaufaniu/questach.

## Warsztat

Nie musi być osobnym NPC w pierwszej wersji.

Usługi docelowe:
- podstawowa broń;
- amunicja;
- naprawa;
- proste ulepszenia.

Vertical slice:
- może być statycznym stanowiskiem/sklepem.

## Odpoczynek

Funkcje:
- przesunięcie czasu;
- opcjonalne leczenie;
- checkpoint/autosave.

Nie powinien być darmowym exploitem resetującym każdy stan świata bez konsekwencji czasowej.

## Crossing service

Po rozwiązaniu:
- bezpieczniejsze przejście;
- potencjalny skrót;
- informacja o stanie drogi.

## Shrine

Usługi:
- nauka rytuału;
- nauka znaku;
- opcjonalny divine interaction.

Brak patrona nie blokuje.

## Handel

Pierwszy vendor może mieć prostą ofertę:
- bandage;
- basic arrow później;
- ingredient;
- tonic po unlock.

## UI

Każda usługa jasno pokazuje:
- koszt;
- efekt;
- wymaganie;
- brakujący zasób.

## Persistence

Unlock usług jest trwały, jeśli wynika z questa/reputacji.
