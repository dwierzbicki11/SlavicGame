# Day/Night Event Table — v0.1

## Cel

Pora dnia zmienia plan gracza, a nie tylko kolor nieba.

## Fazy

- Dawn: 05–07 roboczo;
- Day: 07–18;
- Dusk: 18–20;
- Night: 20–05.

Dokładne granice mogą zmieniać się sezonowo później.

## Żarnowiec

Day:
- vendorzy;
- praca;
- rozmowy;
- ruch.

Dusk:
- ludzie wracają;
- guard zmienia patrol;
- usługi zaczynają się zamykać.

Night:
- ograniczone usługi;
- night watch;
- mniej NPC na zewnątrz.

## Puszcza Żywia

Day:
- zbieranie;
- prace leśne;
- physical tracks czytelniejsze.

Night:
- inne ambience;
- neutral guardian encounter;
- wybrane supernatural traces.

## Czarne Mokradła

Day:
- oględziny;
- przeprawa;
- predator traces.

Night:
- boundary leak active;
- apparition;
- wyższe ryzyko predatora;
- ritual/quest window.

## Kamienny Krąg

Day:
- badanie znaków;
- nauka.

Night:
- aktywacja rytualna;
- opcjonalny divine messenger/manifestation później.

## Missed window

Jeśli gracz przegapi noc:
- może poczekać/odpocząć;
- event wraca kolejnej nocy;
- quest nie failuje.

## Event priority

Quest event > unique encounter > schedule > ambient.

## Persistence

Jednorazowe eventy zapisują flagę wykonania.
