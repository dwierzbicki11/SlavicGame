# Epilogue Matrix — v0.1

## Struktura

Epilog =

```text
GlobalEnding
+ RegionOutcome[]
+ NPCOutcome[]
+ PoliticalOutcome[]
+ DivineOutcome[]
+ FamilyOutcome
+ HunterOutcome
```

## Żarnowiec

### Jeśli przeprawa stabilna
- handel wraca;
- osada rośnie umiarkowanie.

### Jeśli pact apparition pozostał
- nocne reguły wchodzą do lokalnego zwyczaju.

### Jeśli predator żyje
- okolica zachowuje ograniczenia.

### Jeśli anchor zniszczony
- rodzina zachowuje mniej pewności co do ostatnich chwil zmarłego.

## Nadborze

Osie:
- centralizacja;
- autonomia;
- kontrola węzłów;
- stosunek do łowców.

## Wielki Bór

Osie:
- eksploatacja;
- lokalne prawa;
- stan guardianów/miejsc;
- dostęp do węzłów.

## Przymorze

Osie:
- wolny handel;
- blokady;
- kontrola ujścia;
- reakcja na nowe przejścia między sferami.

## Kamienne Wyżyny

Osie:
- własność kopalń;
- stan przełęczy;
- wydobycie materiałów do kotwic.

## Arel

Osie:
- zachowanie dróg sezonowych;
- granice;
- sojusze;
- dostęp do starej wiedzy tras.

## Polityka

Możliwe epilogi:
- silniejsze Nadborze;
- federacja;
- rozpad związku;
- kompromis z Ligą;
- konflikt celny;
- nowa rada progów.

## Bogowie

Dla każdego istotnego boga:
- relation;
- contract;
- institution state;
- access to Jawia;
- manifestation status.

## Rodzina

### Prawda poznana
Bohater wie:
- kim byli rodzice;
- co zrobili;
- dlaczego został ukryty.

### Prawda częściowa
Bohater zna część, ale nie Parent B / pełny mechanizm.

### Prawda pominięta
Główna decyzja nadal możliwa dzięki innym badaczom, ale epilog rodziny pozostaje otwarty.

## Bohater

Możliwe role po grze:
- aktywny łowca;
- nauczyciel;
- opiekun węzłów;
- niezależny badacz;
- polityczny mediator;
- agent instytucji;
- wędrowiec.

Nie zamykamy postaci w koronie/małżeństwie bez wyboru gracza.

## New Game / continuation

Stan świata po zakończeniu może być podstawą:
- epilogu;
- DLC/sequela;
- post-game

ale post-game nie jest wymagany do 1.0.
